# Imágenes de Productos FFT hemtec

Esta carpeta contiene las imágenes de los productos de la familia FFT hemtec.

## Imágenes requeridas:

Basándose en el archivo `hemtec-products.json`, necesitas las siguientes imágenes:

1. `FFT_hemtec_Single_S.png`
2. `FFT_hemtec_Single_F.png`
3. `FFT_hemtec_Single_Y.png`
4. `Single_SA.png`
5. `Twinstep.png`
6. `Verso.png`
7. `VersoA2.png`
8. `VersoA4.png`
9. `FFT_hemtec_VersoM.png`
10. `FFT_hemtec_VersoMP.png`
11. `FFT_hemtec_VersoML.png`
12. `180_degree_hemming_machine.png`
13. `roller_cleaner_machine.png`
14. `laptop_displaying_HemQC_Force_software.png`

## Especificaciones de imagen:

- **Formato**: PNG o JPG
- **Resolución recomendada**: 800x450 píxeles (16:9)
- **Tamaño máximo**: 500KB por imagen
- **Fondo**: Preferiblemente transparente o blanco

## Imagen de respaldo:

Si alguna imagen no se encuentra, se usará `main-hero.webp` como imagen de respaldo.
